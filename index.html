Como funciona: a maioria dos geradores tipo "html-code-generator.com" só embrulha o HTML real dentro de document.write(unescape('...')) (percent-encoding, %3C = <) ou document.write(atob('...')) (base64). Isso não é criptografia — é reversível sem chave nenhuma. Cole o script inteiro (com ou sem as tags <script>) e a ferramenta detecta automaticamente qual dos dois formatos foi usado.
